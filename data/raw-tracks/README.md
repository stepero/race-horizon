# Zdroj dát tratí

Stredové čiary a šírky tratí pochádzajú z projektu
[TUMFTM/racetrack-database](https://github.com/TUMFTM/racetrack-database)
(Technical University of Munich, licencia LGPL-3.0, pozri LICENSE-LGPL-3.0.txt).
Súbory sú nezmenené CSV: `x_m, y_m, w_tr_right_m, w_tr_left_m`.

Okruhy bez dát v tejto databáze (Miami, Monako, Madring, Baku, Singapur, Las Vegas, Katar)
generuje `scripts/build-tracks.mjs` ako jasne označené dočasné trate (`placeholder: true`).
